## Task
MyoSuite `myoHandKeyTurnFixed-v0` (MyoHand, a musculoskeletal model of a human forearm and hand, 39 muscles): Turn the key held between the thumb and the index finger by more than 3.14 rad (half a turn). Success: the key's hinge angle above 3.14 rad for 50 consecutive control steps (1.0 s). Failure (the episode ends): the index or thumb tip more than 0.10 m from the key head.
The key sits in a lock in front of the palm; its head is between the thumb and the index finger. The deliverable is one replayable trajectory of actuator commands (`/app/output/trajectory.npz`, `(T, 39)`, one row per 20 ms control step).

## Difficulty
First-pass rating: medium. The action is muscle-level (39 muscles, each only pulling, several crossing more than one joint, with activation delays): the agent has to build its own joint control from muscle excitations. MyoSuite's goal has to hold for 1.0 s, so passing through the goal does not count.

## Reference solution
MyoSuite's own NPG baseline policy for `myoHandKeyTurnFixed-v0` (`myosuite/agents/baslines_NPG/`, shipped in the MyoSuite wheel and removed from the image), rolled out from the frozen instance and cut at the first success: `solution/oracle.npy`, 72 rows (float32-exact, so the standard twin's client executes the same rows), success after 72 control steps. Replayed and saved by `solution/solve.sh`; re-checked by `scripts/myosuite/make_facts.py --oracles` (two fresh sessions, same final state).

## Verification
`tests/grade.py` in a separate sandbox without network: two replays of `/app/output/trajectory.npz`, each in a fresh process, from the verifier's own copy of the instance (`tests/instance.npz`; the rebuilt start state is checked against its recorded hash); pass iff both episodes end in success (the goal held 50 control steps) in the same state (`deterministic`). `nop`: no trajectory, reward 0.
