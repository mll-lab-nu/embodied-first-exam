# kinder-base-motion-3d-i00

KinDER `kinder/BaseMotion3D-v0` (Kinematic3D, PyBullet), seed 0, full mode: the agent has the simulator and its state and
hands in one trajectory, replayed open-loop in a fresh process. Its limited-mode twin is `kinder-base-motion-3d-i00-limited`.

Task: drive the robot's base to the small red ball (`target`) that hovers 0.2 m above the floor. The task succeeds the moment the base's position (`robot`'s `pos_base_x`, `pos_base_y`) is less than 5 cm from the ball's centre, measured horizontally; the base's heading is not checked.

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
