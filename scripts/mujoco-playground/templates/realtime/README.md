# {{name}}-standard-realtime

## Task
MuJoCo Playground `{{env}}` ({{robot_name}}) on the same frozen instance as `{{name}}-privileged`: {{task}}
{{task_detail}} Standard-realtime mode (eai-standard/2.3, slowdown S = {{slowdown}}): once an episode's clock starts the
robot runs at {{control_hz}} Hz whatever the agent does; it drives the robot through the realtime client from a program
of its own, with {{rt_resets}} resets (only the last episode is graded), the robot's own sensors and the cameras that
follow it.

## Difficulty
Same instance and success check as `{{name}}-standard`. The scene is dynamic (`scripts/task_dynamics.toml`: {{dynamic_why}}),
and here time does not stop: the robot falls within a second without active balance and the pushes come at moments
the agent is not told, so nothing can be steered call by call. The agent has to write a feedback controller that runs
at the control rate in its own container, and learn the robot from {{rt_episodes}} real attempts.

## Reference solution
`solution/oracle_plan.py` plans the privileged reference's rows (`solution/oracle.npy`, {{n_rows}} rows) into the episode
from its first control step (`submit(..., at=0)`); it uses no privileged information at run time. On the clock the rows
run at the same control steps as in the privileged replay, and the episode ends {{oracle_end}}.

## Verification
The sim service (`environment/sim/rcb_realtime.py` + `rcb_service.py`, the shared eai-standard/2.3 layer, with
`environment/sim/server.py`, this benchmark's adapter) judges the episode live and records every control step it ran
(`trajectory_live.f64`); after the agent's time the collect hook stops the agent's programs and signals the service,
which replays the graded episode in a fresh `rcb_quadruped.Session` and writes `final.json`; `tests/grade.py`
(separate sandbox, no network) passes iff the live check succeeded, the replay succeeds and ends in the same state. The
clock's record (`stalls`, `max_lag_s`, ...) is copied into `reward.json` and decides nothing. {{check_short}} `nop`: the
episode never starts (its clock starts at the first submit), reward 0.
