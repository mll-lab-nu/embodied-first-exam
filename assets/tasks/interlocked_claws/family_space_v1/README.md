# Interlocked Claws family space v1

`plan.json` defines three categorical motion/structure families and nine representative design targets.
It is a planning specification, not a generated-model catalog or an enabled random sampler.
All numeric ranges are proposal bounds; all validated bounds are null.

- A: source Claw spatial weaving — classic / wide shallow hooks / tall deep hooks.
- B: coupled axial rotation and advance — balanced / squat wide / tall narrow crown.
- C: two ordered orthogonal turns — balanced / wide bridge / tall deep cavity.

A0 has archived ideal-grasp-assisted reference execution evidence, but its independent contact controls failed.
The other eight models and IK traces have not been constructed or certified.
No instance is currently eligible for the proposed release protocol.
