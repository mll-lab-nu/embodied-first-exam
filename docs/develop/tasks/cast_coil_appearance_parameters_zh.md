# Cast Coil：保持已有解法的三个外观参数

后续已将方案细化为[三个 IK 家族与九个可见代表点](cast_coil_family_space_zh.md)：每个家族以自身机制尺寸、厚度和轮廓微调组成条件参数空间。该文记录新增代表点的几何与 IK 检查；本页保留最初三个通用外观参数的试验依据。

适用种子：`eccentric_turn`、`split_turn_offset`、`axial_screw_turn`。选择其中一个解法家族，再在家族内联合采样三个外观参数。以下为设计提案与几何验证，不是新增完整机器人 demo 的验收。

## 参数定义与首版范围

| 参数 | 外观作用 | 首版范围 | 派生实际尺寸 |
| --- | --- | --- | --- |
| `face_scale = s` | 正面方框整体大小 | 0.95–1.05 | 宽和高均为 `102s mm`，即 96.9–107.1 mm |
| `depth_scale = d` | 四层交错结构的总厚度 | 0.90–1.10 | 深度 `74.25d mm`，即 66.825–81.675 mm |
| `corner_cut_ratio = q` | 正面四个外角的切角，形成更明显的八边形外轮廓 | 0–0.25 | 以种子银件 21 mm 边框宽度为共同基准，切角长度 `c = 21sq mm`，上限约 5.5 mm |

两个零件一起变换。`s` 同时改变 x、z；`d` 改变局部 y。厚度变化也同步缩放层间距和通道，不能只增厚材料而保留旧间隙。切角沿局部 y 贯穿各层，仅削除四个外角，不进入抓持面、锁止通道或桥接根部。

目前零件为显式盒组合，不能只修改旧模板的 `outer_width` 等字段；需要变换真实实体和配套轨迹。切角初探采用 0.75 mm 正交阶梯近似，尚未生成光滑 CAD 倒角。

## 为什么能保留解法

令设计坐标变换 `A = diag(s, d, s)`。当前三个家族的相对转动均绕 y 轴，因此所有转动矩阵都满足 `AR = RA`。

若原路径为 `R(u)x + t(u)`，新实体使用 `Ax`，新路径使用相同 `R(u)` 和 `At(u)`，则其运动结果就是原运动的线性变换。转轴、分段错位和螺旋推进向量也必须乘以 A。A 可逆，原来互不相交的两件沿变换后的路径仍互不相交；再削去外角材料不会新增件间碰撞。

这就是 x、z 同比缩放的原因。独立改变正面长宽比时，一般不再满足上述交换关系，需重新反推转动通道，不能继承这项保证。

本轮将三个原种子的理想路径重新认证到至少 **0.20 mm** 连续分离余量。候选范围中 A 的最小奇异值至少为 0.90，因此变换后理想路径具有至少 **0.18 mm** 的欧氏分离下界；切角只增加自由空间。这是零件之间的几何结论，不包含机器人、桌面或受力跟踪误差。

## 联合采样规则

1. 先选择已有解法家族，再采样 s 和 q，生成并检查切角后的未缩放实体。
2. 计算每个零件保留体积比例 `r_i(q)`。密度保持不变，质量比为 `m_i / m_i0 = s² d r_i(q)`。
3. 首版为控制对已有控制器的扰动，建议每件质量比限制为 0.90–1.10。这是工程筛选条件，不是稳定抓持的充分条件。按此确定 d 的条件区间：

   ```text
   d_low  = max(0.90, max_i 0.90 / (s² r_i))
   d_high = min(1.10, min_i 1.10 / (s² r_i))
   d ~ Uniform(d_low, d_high)
   ```

   区间为空则重采 s、q；不把独立采样结果强行裁到边界。当前三个范围内的小样本已有可接受组合。
4. 切角只能落在预先定义的外角区。最大切角的未缩放 x、z 均在外缘 5.25 mm 内，与已有抓持保护区的 x 范围分离。保留桥接根部和锁止通道，检查水密性、单一连通组件及局部最小厚度。
5. 同步派生转轴、位移、抓点、初始离桌高度和抬升要求，重算质量惯量。机械臂关节角需要重新求 IK。
6. 输出有效实例前，复核指定路径的连续碰撞、六方向直拉与原版路径负对照、机器人可达性/碰撞、放置和释放。计划用于正式物理 demo 的实例还需完成受力执行及半时间步复核。

首版不建议把“解锁缝隙”也当作自由外观参数：当前物理执行的最小采样间隙约 0.15–0.28 mm，未经重算直接移动槽壁会侵占这部分余量。

## 本轮有限验证

证据目录：[`runs/environment-solvability/cast_coil/appearance_parameters_20260917/`](../../../runs/environment-solvability/cast_coil/appearance_parameters_20260917/result.json)。

- 每个家族测试 5 组 `(s,d)`：`(.95,.90)`、`(.95,1.10)`、`(1,1)`、`(1.05,.90)`、`(1.05,1.10)`。
- 每组测试种子坐标下切角长度 0、3、5.25 mm，共 **45 组**。
- 45 组均通过实体水密/连通/绕向检查、理想路径连续证书；原版路径和六方向直拉均保留真实重叠见证。
- **27 组**满足建议的每件质量比 0.90–1.10；其余因过重或过轻被联合规则排除，不是几何无解。
- 初次 CSG 的一组阶梯切角遇到浮点近重合平面导致的非水密网格。将重合坐标统一到 `1e-12 m` 后通过；原始失败报告和探针源码均保留。正式生成器应统一坐标平面并拒绝无效实体。
- 整个 s、d 范围的连续件间几何依据见 `seed_margin_certificate.json`；45 点不能替代全部外形有效性或随机生成成功率的验证。
- **尚未为这些新外观参数重跑 IK 或机器人动力学，也没有测量连续随机采样的接受率。**正式参数分布应在批量机器人检查后收紧，并记录失败率和原因。

例如可先展示三种外观：`(s,d,q)=(.95,1.10,0)` 的紧凑厚框、`(1.05,.95,.25)` 的大面薄框切角、`(1,1,.25)` 的基准尺寸切角。它们仍属于所选种子的解法家族。
