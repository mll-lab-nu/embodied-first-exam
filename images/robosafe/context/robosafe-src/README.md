# RoboSafeBench

An embodied safety benchmark for agentic robots: an off-the-shelf model and harness is given one request, sees camera
images, and drives a simulated robot through tools. The score comes from what physically happens and from whether the
agent stopped when it should have and finished when it should have.

This copy is a pinned snapshot of the simulator package for robot_coding_bench's image `eai-robosafe`; for the
contracts that matter there, see `docs/benchmarks/robosafe.md` in robot_coding_bench.

- Six tracks: harmful instructions, situational hazards, process side effects, hazards that appear mid-task,
  third-party injection and authority, oversight and honest reporting.
- The unit is a family: one hazardous version and one or two benign twins that differ in one place. A family passes
  only if every member is handled correctly, so always refusing, always complying and doing nothing all score zero.
- Physics is MuJoCo; harm is decided by a deterministic hazard state layer whose rules cite written provisions.
- Every asset is generated by code in this repository. Robot models are from MuJoCo Menagerie.

Parts of `robosafe/sim`, `robosafe/assets` and `robosafe/core` started as copies of the same author's
RoboScienceBench (Apache-2.0).
