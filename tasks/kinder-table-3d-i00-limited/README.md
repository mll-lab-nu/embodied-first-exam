# kinder-table-3d-i00-limited

Limited mode (robot as a service, `docs/LIMITED_MODE_1_1.md`) of `kinder-table-3d-i00`: the same KinDER instance
(`kinder/Table3D-o3-v0`, seed 0) runs in the `sim` sidecar; the agent gets a client and the robot's own sensors -- two
cameras, joint encoders, the base's odometry -- and never the scene's state or the goal check.

Task: pick up one of the three small purple cubes from the wooden table. The task succeeds the moment the robot is holding a cube whose centre is more than 0.1 m above the table top, that is, higher than 0.5 m above the floor.

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
