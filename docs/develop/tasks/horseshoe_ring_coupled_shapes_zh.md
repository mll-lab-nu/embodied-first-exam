# Horseshoe Ring：耦合形状变体 v1

本轮把马蹄轮廓、目标环椭圆度和链节长度接入了实际视觉网格与碰撞几何，并为新形状调整了完整取环路径。目前有 **4 种基础轮廓／椭圆组合、10 组参数参考实例**通过全过程连续几何检查。

这些是独立刚体的可解性证据。新形状尚未完成对应的 ALOHA 抓取、IK、自碰撞和力驱动执行；`body_poses.json` 是零件姿态路径，不能当成机器人 IK trace。原有机器人视频仍保存在 `runs/demos/horseshoe_ring/` 的各变体目录。

## 已验证的参数组合

| 参考族 | 轮廓 s | 目标环长短半轴比 e | 链节长半轴 L，模板 mm |
| --- | ---: | ---: | --- |
| waist_mild | −0.5，轻度收腰 | 1.05 | 18 |
| waist_ellipse | −0.5，轻度收腰 | 1.15 | 17、17.5、18 |
| u_mild | +0.5，较方的 U 形原型 | 1.05 | 17、17.5、18 |
| deep_waist | −1，较强收腰、局部轻微内凹 | 1.05 | 17、17.5、18 |

“较强”只指相对于本轮其他轮廓。当前内凹和 U 形改动仍较温和，不等同于已经重建市售深凹马蹄铁。页面提供与原始轮廓的叠图，便于判断实际变化幅度。

当前每侧保持 **1 个链节**；L 改变这个链节的长轴，不改变链节数。场景尺度是 2，因此 L=17/17.5/18 对应中心线长轴全长 68/70/72 mm。链节短半轴固定 5 mm，线材半径固定 0.7 mm，均为模板尺寸。模板数据的 mm 需要乘场景尺度后才是场景中的实际长度。

上表是通过验证的离散组合，**不是** s、e、L 可以任意交叉组合的区间。尤其不能把 e=1.15 直接用于所有 U 形。

## 参数如何联动

`shape_variants.make_template` 实现候选几何规则：

1. 固定马蹄两端连接孔的位置、孔尺寸、两侧链节数和装配拓扑，防止轮廓一变就失去互套关系。
2. 用 s 控制轮廓：s≥0 时超椭圆指数 p=2+s；s<0 时收腰幅度 d=−4s mm。参数化变形在连接端进行补偿，使端点保持原位。
3. 马蹄轮廓的纵向半径设为 `29 + 31(e−1) + d` mm，让椭圆度与马蹄外宽联动。
4. 从实际生成的马蹄带状网格计算外包络半宽 W；目标环长半轴 `A = W + r − b`，短半轴 `B = A/e`，r 为目标环线材半径。b 约为 0.798–0.800 mm。这使目标环最大内半轴比马蹄外半宽略小，抑制“只把环做大就可以直拉取下”的退化。
5. 初始环内相位暂时固定 0°；求解路径允许环平移、改变法向及绕自身法向转动。不能把环的相位当作与其他参数无关的任意随机量。

这些尺寸规则用于提出候选，尺寸关系本身不证明可解。代码允许搜索 s∈[−1,1]、e∈[1,1.35]、L∈[16,20]；这是**候选输入范围**，不是经过证明的可解范围。

## 检查结果与边界

- 10 个参考实例均从正确初始装配开始，通过五个零件全部 10 对碰撞几何的连续检查，最终目标环与其余装配的包围盒完全分离。参考路径要求至少 0.10 mm 保守间隙。
- 检查覆盖关键帧之间的 COM 线性插值和最短四元数 SLERP。只检查初态、终态或关键帧不足以证明路径可行：三个早期候选就在关键帧之间发生了碰撞。新增的局部绕行规划修复了这些段，并重新检查了全过程。
- 四个基础参考实例沿初始 ±X 直接拉环均未通过检查，保持了基本的解谜要求。这只排除了这两种直拉策略，并不证明最短解、抓取次数或整体难度。
- `waist_ellipse` 的翻折段相对原始路径使用了约 **58.66°** 的额外环内转角。保留同一平移和法向变化、去掉这部分转角后，392 个采样中有 154 个低于要求的间隙，其中 153 个发生接触／相交。这个消融说明该转角对这条路径有作用，不证明所有可能的解都必须经过同样的相位。
- s=+0.5、e=1.15 的候选出现两只马蹄之间的碰撞，未收录。L=16、18.5、19、20 的测试出现不同的间隙不足或相交，不能直接沿用这些路径。L 的 24 帧间隔筛查保存在 `chain_probe.json`；筛查通过仍需要全过程验证。

几何检查是数值保守界，针对导出的凸体／胶囊碰撞模型；没有加入制造公差、摩擦、机器人夹持、实验室障碍物或接触动力学。这些限制在证书中分别标明。

## 稳定随机生成规则

采用“已验证参考族＋联合扰动”的采样方式，生成的是多个参考实例附近的可解区域。

先均衡地随机选参考族，再提出 `Δs∈[−0.08,0.08]`、`Δe∈[−0.005,0.005]`、`ΔL∈[−0.45,0.45]`。重新生成几何，并计算每个零件的保守形变界 δ。新 COM 按参考姿态重定位；因为帧间插值以 COM 为中心，还要加入旋转导致的插值误差界。

对全部 10 对零件同时要求：

```
参考连续间隙下界(i,j) − δ(i) − δ(j) ≥ 0.05 mm
```

如果任意一对不满足，就把**整组三个参数的增量一起减半**，直到所有约束通过，再检查初始互套关系和终态完全分离。每个输出均保存它自己的模板、完整路径、证明及来源哈希；不输出未经验证的候选。

因此实际连续扰动通常比较小：首批 12 个样本的 s 变化约 0.01 量级、e 变化约 0.0004 量级、L 变化约 0.03 mm 量级。可见的主要差异来自参考族的切换。后续 30 个样本覆盖全部 10 个参考实例，包括更短链节。两批共 42 个输出均通过证明转移；具体值和联合收缩系数见各批 `report.json`。**不能把样本的各列最小／最大值拼成一个新的可解参数盒。**

若要较大的连续形变，应走较慢的分支：生成候选 → 保留连接约束并调整零件路径 → 修复帧间绕行 → 完整连续检查 → 加入新的参考族。局部优化和运动规划都可能失败，不能承诺任意大形变都成功，也不应把失败候选标成无解谜题。

## 产物与使用

结果目录：

```
/home/jianwen/topogym/runs/environment-solvability/horseshoe_ring/coupled_shape_variants_v1/
  index.html                 # 可离线打开的完整几何回放；含旋转视角与进度条
  review_data.js             # 本地回放数据，无 CDN 或 fetch 依赖
  references/<id>/           # 10 组模板、完整路径、连续证书及 GLB/URDF
  samples_seed17/<id>/       # 第一批 12 个联合随机样本
  samples_seed29/<id>/       # 第二批 30 个联合随机样本
  controls.json              # 直拉与相位消融
  chain_probe.json           # 链长筛查失败与通过记录
```

生成新的随机批次（从项目根目录运行，输出目录必须是新的或空目录）：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=. \
  .venv-gs121/bin/python -m topogym.tasks.horseshoe_ring.shape_sampler \
  --count 20 --seed 2026 \
  --output runs/environment-solvability/horseshoe_ring/coupled_shape_variants_v1/samples_seed2026
```

单个结果可以用原连续检查器独立复验：

```bash
PYTHONPATH=. .venv-gs121/bin/python -m topogym.tasks.horseshoe_ring.independent_motion \
  <样本目录>/body_poses.json --margin-mm 0.05 \
  --output <样本目录>/independent_recheck.json
```

源代码为 `shape_variants.py`（候选与局部路径调整）、`shape_bridge.py`（取环绕行）、`shape_neighborhood.py`（连续界转移）、`shape_sampler.py`（稳定采样）、`shape_review.py`（结果页）。导出的实际形状由 `geometry.py` 统一生成。旧机器人抓取代码已对这些形状明确拒绝套用，避免把原有圆环抓取点误当成新椭圆环上的合法接触点。
