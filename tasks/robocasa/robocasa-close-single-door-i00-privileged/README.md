## Task
RoboCasa's `CloseSingleDoor` kitchen task with a Franka Panda arm on an Omron mobile base (with a torso lift): Close the microwave door. Produce one replayable trajectory of the robot's native controller commands on one frozen instance; graded on the state after the last action. Generated by `scripts/robocasa/generate.py`; benchmark notes in `docs/benchmarks/robocasa.md`.

## Difficulty
Full privileged state, unlimited resets and self-replay; a mobile manipulator in a cluttered kitchen, long-horizon contact-rich manipulation with a 20 Hz controller. The standard twin removes the privileged state.

## Reference solution
The demonstration's own actions (original: 265 actions), executed from the frozen scene by the robot's own controller: 265 actions in `solution/oracle.npz`. The demonstration is a reference solution: it is not in the image and the agent cannot reach it.

## Verification
`tests/grade.py` in a separate sandbox without network: two replays in fresh processes from the verifier's own copy of the instance; `success = deterministic ∧ success on the final state ∧ not solved at the start`. Reference: two fresh-process replays end in the live run's state (hash `4b949423cfb2…`) and succeed. `nop`: no trajectory, reward 0; the instance is not solved at the start.
