# kinder-tossing-i00-limited

Limited mode (robot as a service, `docs/LIMITED_MODE_1_1.md`) of `kinder-tossing-i00`: the same KinDER instance
(`kinder/Tossing3D-o1-v0`, seed 0) runs in the `sim` sidecar; the agent gets a client and the robot's own sensors -- two
cameras, joint encoders, the base's odometry -- and never the scene's state or the goal check.

Task: get the green cube lying on the floor into the yellow bin on the far side of the low wall that runs across the room. The task succeeds the moment the cube's centre is inside the bin's goal region, the translucent green box marked in the bin.

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
