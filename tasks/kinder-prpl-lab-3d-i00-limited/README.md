# kinder-prpl-lab-3d-i00-limited

Limited mode (robot as a service, `docs/LIMITED_MODE_1_1.md`) of `kinder-prpl-lab-3d-i00`: the same KinDER instance
(`kinder/PrplLab3D-o2-v0`, seed 0) runs in the `sim` sidecar; the agent gets a client and the robot's own sensors -- two
cameras, joint encoders, the base's odometry -- and never the scene's state or the goal check.

Task: put the two small orange blocks lying on the floor on the kitchen counter in front of the robot, whose top is 0.828 m above the floor. The task succeeds the moment neither block is held and each block's centre is at least 0.778 m above the floor (5 cm below the countertop's top surface).

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
