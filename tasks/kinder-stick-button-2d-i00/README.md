# kinder-stick-button-2d-i00

KinDER `kinder/StickButton2D-b10-v0` (Kinematic2D), seed 0, full mode: the agent has the simulator and its state and
hands in one trajectory, replayed open-loop in a fresh process.

Task: press all ten red buttons (`button0`–`button9`): six are on the white floor and four on the black table that fills the upper half of the scene; a brown stick (`stick`) stands at the far left, reaching from the floor up across the table's edge. A button turns green, and stays green, the first time the stick or any part of the robot overlaps it (base, arm, gripper, and the suction area in front of the gripper while the vacuum is on); the task succeeds the moment all ten are green.
