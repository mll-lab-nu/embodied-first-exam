1.3 场景 3DGS 底座（现状：仍是瓶颈）

场景重建质量目前还不够好 —— 后处理类方案试过，实际收益有限；结论是问题出在采集端。

稠密帧重训（3882 帧，6.6× 帧密度）没解决问题 工程加速：分片并行匹配 15 min（原 CPU 6.7 h） 下轮方向：fps 30 + splatfacto 扫描策略（改采集，不改后处理）

1.4 Limitation：其他场景重建不佳 → 采样策略要改

box5 / bag1 / bag2 / hang1 / cross1 五个场景重建都不理想。定位到视角采样：这批采集是「盯细节」而非「求覆盖」。

下一轮重拍：fps 30 + 最大覆盖优先（内外双环 × 多高度层，保证每个表面被多个方向看到），再对重点物体补细节段。

PART 2

FK 3DGS 重训练

机器人本体 3DGS 的重建与改进（本部分由另一位同学负责）

2.1 训练配方重设计（E 配方）

旧主干靠一堆末端补丁才能保住夹爪；新配方把补丁全撤掉，只改初始化 + 约束 + 训练流程。

初始化mesh 表面构造CAD 面片直接撒高斯，材质色写进 SH 直流项 —— 起点就是正确形状
→
几何约束bounded + 每面保底高斯只能在所属面片 3 mm 内漂移；每面片保留最后一个高斯，末端不会被剪光
→
训练随机背景 + 多视 batch深度掩码合成随机底色抑制漂浮；每步 6 视角 + SH 逐级放开 + 位置学习率余弦退火
→
一致性训练=评测=消费端光栅化模式两端必须一致（错配实测 −3.4 dB）；相机内参从数据反推，不写死

2.2 相对线上旧版，肉眼差多少（Franka）

CHORD 目前用的还是 4 月那版 franka 权重（219,608 高斯）。同一批 100 个 novel pose、同一相机，重新渲一遍摆在一起看。

夹爪区域 IoU 0.656 → 0.870 整机轮廓 IoU 0.925 → 0.966 全局 PSNR 31.89 → 33.07 dB 高斯数 220k → 205k（反而更省）
模型全局 PSNR机器人区 PSNR轮廓 IoU夹爪区 IoU
线上旧版（2026-04, 220k）31.8920.250.9250.656
本周 E 配方（203k）33.0721.160.9660.882
本周交付版（205k，跨数据集）32.0320.290.9660.870
口径说明：夹爪区 IoU = 把 hand + 两指的高斯合起来与 GT 掩码比。单看"每根手指自己的高斯"会受高斯归属影响（交付版有一部分指尖像素是由相邻 link 的高斯画出来的，per-link 0.48 但合成 0.87），合成口径才对得上肉眼。

2.3 新旧架构全量对决（Franka · 100 novel pose）

同一批测试姿态、同一相机。全局 PSNR 看不出差别 —— 差别全在末端。

夹爪指尖 per-link IoU 0.420 → 0.780 末端平均 IoU 0.593 → 0.822 轮廓 IoU 0.952 → 0.966 高斯数 375k → 203k（−46%） 全局 PSNR 33.42 → 33.07（打平）
旧栈要靠"末端特写训练层 + 夹爪专项微调"才能把这个指标救到 0.786；新配方零末端特殊化直接到 0.780，那套补丁已整体退役。

2.4 相机药方：哪里糊，就给哪里配相机

监督覆盖不到的地方一定糊。按部位补三类专属相机，逐轮把模糊区域打掉。

整机测试集 PSNR V4 29.54 → V6 29.64 dB 关节特写测试集 PSNR V4 20.72 → V6 20.93 dB 轮廓 IoU 0.9667 → 0.9687

2.5 面系绑定消融（负结果，已归档）

试过把各向同性的 3 mm 球形约束换成沿面法向压扁的各向异性约束（切向 3 mm / 法向 1 mm）。

2.6 Mitsuba 外观域：必须一体训，不能只换外观

把模型迁到物理渲染域时，最初做法是锁死几何、只重训外观。对照实验证明这条路是错的。

冻结几何·只训外观（5k）39.98 dB 全参数一体训（同 5k）41.05 dB 一体训 10k 41.08 dB（已收敛） Franka：旧 ckpt 38.46 → 定版 38.77 dB

2.7 棚拍域（S3）：两个杠杆都没用

加了 key/fill/rim 三灯棚拍环境后质量掉一档。做了 2×2 消融找原因：视角密度和致密化窗口都不是瓶颈。

6 机位 31.00 dB 12 机位 31.08 dB 6 机位 + 宽致密化 31.07 dB 12 机位 + 宽致密化 31.13 dB 四臂全部落在 ±0.14 dB 内（σ=2.4）

⑤ 当前主要问题

接触 contact 不正确 手/夹爪与箱盖没有真正建立接触关系：存在穿插、悬空推动，动作看起来「隔空生效」。
材质 环境材质有待改进 场景表面缺少可分离的材质属性（粗糙度/反照率），插入物体与环境的观感一致性受限。
光照 光照未被很好解决 已能解出主光源并投出真实阴影，但整体一致性仍不足；是否为当前瓶颈尚不确定，需与接触问题分离验证。
