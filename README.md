# Embodied First Exam

**Can a coding agent program a robot?** Robot-manipulation tasks for coding agents (Claude Code, Codex, …) in the
[Harbor](https://github.com/harbor-framework/harbor) task format, each in a privileged mode (the agent holds the
simulator), a standard mode (robot as a service) and, for dynamic tasks, a standard-realtime mode.

**Website, leaderboard and videos: [embodied-first-exam.ai](https://embodied-first-exam.ai)**

## Quick start

```bash
git clone --recurse-submodules git@github.com:mll-lab-nu/embodied-first-exam.git && cd embodied-first-exam
uv tool install --force -e . --with-executables-from harbor     # harbor 0.23.0 with the flags below
cp .env.example .env

harbor run -a codex -m openai/gpt-6-luna              # core set (default, --core)
harbor run --all -a codex -m openai/gpt-6-luna        # every task
harbor run --standard -a codex -m openai/gpt-6-luna   # --privileged / --standard / --standard-realtime
harbor run -p tasks/<task> -a oracle                  # one task
```
