# Lock-picking 固定家族库 v1

`catalog.json` 固定 F1/F2/F3 的槽位、限位、角度序列及一个已记录的机械臂 IK 初值。
分别具有 1/2/3 次必要回退；三齿不变。生成时直接选择固定机构，不再随机重设计槽口。
来源摘要与 SHA-256 保存在 `provenance`；运行时不读取历史 `runs/`。

尺寸、平移、颜色与表面参数由 [生成器](../../../../topogym/tasks/lock_picking/variants.py)
按 seed 采样。每个接受实例保存所选原型、IK 初值和完整配置；重载不重新采样、不读取本库。
库或生成规则发生有意义变化时应增加版本，旧实例仍以其快照为准。

这些是几何与 IK 原型，不是新结构的动力学成功资格。F2 为 28°/32° 两次复位，
不能借用旧 30°/30° 基线视频的物理验证。接口与验证范围见
[生成器说明](../../../../docs/develop/tasks/lock_picking_seed_generator_zh.md)。
