# 红布解包并取出刚体：任务候选与相机 demo

日期：2026-09-15。

## 判断

**符合新任务的设计方向，建议作为 A3「材料访问与层序控制」的核心候选；正式核心任务验收尚未完成。**

单一目标是解除包覆并取出板。被压住的自由边、上下叠压的布层和剩余包覆共同决定下一步能够抓哪里；翻面、揭层和取板服务于同一个目标。若后续明确检验翻转时保持包裹、解包时防止板滑落，可同时标记 A4「支撑与张力协调」。目标标签为 `release`，对象为布—刚体混合结构。工程目录可放在 `deformation`。

| 要求 | 本任务如何对应 |
|---|---|
| 明确目标 | 板与红布分离，放入独立收纳区；布保持完整 |
| 决定性结构 | 布层遮住下一层自由边，底部开口受板和支撑面压住 |
| 中间依赖 | 暴露哪一层决定下一次抓取；已展开部分影响剩余包覆 |
| 结构变体 | 开口朝上／朝下、上下层顺序、掖入方向与深度、板的形状 |
| 过程验收 | 板—布及布—布不穿透、不撕裂、抓持与支撑符合动作权限 |
| 终态验收 | 板完全脱离布，目标区放置并松手，布不随板被搬走 |

“开口朝下”本身**不证明必须翻转**：侧向抽出板、直接拉出底层布、抬起后抽布或多层一起抓可能是合法捷径。要将“必须翻转”作为能力卖点，需要具体几何、摩擦、可抓区域和允许动作，并对这些基线做实验。类似地，有四层外观不等于必须执行固定四次揭层；成功判据不应要求照抄演示顺序。

## 当前 demo

[三相机同步播放器](../../../runs/cloth_unwrap/opening_down/index.html)

采用共享实验桌面、Nyx、原尺寸 Panda + Robotiq 2F-85，以及 `agentview`、`wrist`、`front_oblique` 相机。外部相机沿用已有正规相机系统并按本任务调整取景；腕部相机随实际 `hand` 连杆移动。

演示采用**一整片连续的十字形红布**，四个布翼依次包住 150 × 72 × 28 mm 的板。不是四块独立布，也没有中途切开材料。100 × 56 mm 的可见窄支撑台给原尺寸指垫和腕部留出侧向夹取净空；初始台高 105 mm，解包台高 90 mm。外层布边仍位于包裹底面与支撑面之间。整包抬起、翻转 180° 后放到解包支撑台，四个布翼逐层向外揭开并垂向桌面，最后夹出板并放到收纳区。成功不要求布料铺成平面。

采用十字形裁片是为了清楚展示连续材料和层序。常见矩形布的角部堆积、斜折和角部自接触仍需独立实现，不能把本示例等同于矩形布包裹的全面验证。

### 实现与证据边界

- 布翼用沿材料弧长积分的可展曲面描述，网格拓扑全程不变；从包覆曲面连续过渡到垂落曲面，不做消失、换网格或整片缩放。
- **布料形状和板的位姿由轨迹规定，PBD 实体只作为动态网格的显示载体，没有推进物理仿真。**
- 机械臂逐帧求 IK，夹爪采用共享原尺寸资产和开口标定；包裹、布边和板采用辅助抓持语义。
- 几何检查包含材料连通性、边长变化、布料顶点与面心对板内部的采样检查、桌面净空；它们不是连续碰撞检测。
- 尚未验证：布料自碰撞、摩擦、真实夹持、无辅助整包翻转、必要翻转证明及策略泛化。

因此，本片可用于评审任务机制和相机可观测性；不能作为物理 oracle 成功率或正式数据采集任务的证据。最终数值见视频目录的 `report.json` 和 `video_validation.json`。
