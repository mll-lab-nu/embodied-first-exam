# {{task_dir}}-standard

Standard mode (robot as a service, `eai-standard/2.1`) of `{{task_dir}}`: the same frozen instance and the same
success rule. HumanoidBench runs in the `sim` sidecar (`environment/docker-compose.yaml`, GPU on the sidecar for
rendering), which holds the reward, judges the episode, records it, replays it in a fresh simulator and renders the
replay video; the verifier grades the sidecar's record in a container of its own (`tests/Dockerfile`, no network).

## Verification
`success` = live success (the episode's return reached the pass mark) ∧ replay success ∧ deterministic (the fresh replay
ends in the live run's state), computed in the sidecar for the last episode (the one after the last reset; earlier
episodes are in `trajectory_live.f64` and `episode.jsonl`, not graded); `tests/grade.py` reads `/data/final.json` and copies the
evidence to `/logs/verifier/` (`replay.mp4`). {{oracle_note}}
