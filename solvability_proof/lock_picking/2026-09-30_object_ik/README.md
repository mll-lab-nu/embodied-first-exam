## 1. 当前模型与问题

沿用当前 Task 的 `lab_tasks_v1` 摆位、150 mm 盘距、495 mm 握柄偏移、三齿钥匙。三个盘分别记为 D1、D2、D3，固定终点板记为 END。锁片角度以 +z 向 +y 为正，即绕世界 −x 轴；钥匙使用相同角度约定。

| 当前变体 | 身份 | D1 槽相位 | D2 槽相位 | D1 限位 | D2 限位 |
| --- | --- | --- | --- | --- | --- |
| easy | F1 / `seed_families_v1` | −30°, 0° | −30° | [−15°, 15°] | [−10°, 45°] |
| medium | `standard_150mm` / `historical_physics_v2` | −60°, −30°, 0° | −60° | [−15°, 15°] | [−10°, 75°] |
| hard | F3 / `seed_families_v1` | −72°, −48°, −24°, 0° | −72° | [−12°, 12°] | [−10°, 87°] |

D3 和 END 的槽相位均为 0°，三个盘的初始角度均为 0°。D3 是 360° 连续转盘；本路径始终保持它为 0°。三片并不都需要改变盘角：真正需要累积角度的是 D2，D1 往复用于换槽，最后所有需要穿过的槽在世界系对齐为 0°。

槽半角 8°，钥匙齿半角 4°，所以每侧角余隙 `m = 4°`。盘厚 10 mm、齿厚 5 mm；钥匙深度定义为 `d = 1 + (x_tip − x_D1) / pitch`。在 `d = 1` 时仅前齿啮合 D1，在 `d = 2` 时前两齿同时啮合 D2/D1；`d = 1.5` 时三齿均在盘间空隙，可以转动钥匙而不带动锁片。

## 2. 构造：锁片只由接触槽壁的钥匙齿驱动

设第一片半行程为 `B`，取实际往复幅值 `b = B − 1°`，避免碰到限位；D1 的第 `j` 个槽相位为 `s_j`，D2 唯一槽相位为 `s_0`。

1. 在盘外将钥匙转至 `θ = s_0`，依次插入 D1、D2。
2. 增大钥匙角度至 `θ = s_j + b + m`。先消除余隙，再由齿面推动两盘；该轮终点为 `α1 = b`、`α2 = s_j − s_0 + b`。
3. 回退至 `d = 1`，D2 保持已有角度。反转钥匙至 `θ = s_j − b − m`，先消除反向余隙，再只将 D1 转至 `α1 = −b`。
4. 前进至空隙 `d = 1.5`，将钥匙转至 `θ = (s_j + s_(j+1))/2`，再插入 `d = 2`，选中 D1 的下一个槽。下一槽与 D2 当前槽的中心仅差 2°，该中点对两片各有 3° 角余量。
5. 重复；选中最后的 0° 槽后，只联动到 `θ = +4°`，得到 `α1 = 0°`、`α2 = −s_0`。将钥匙转回槽中心 `θ = 0°` 时两盘不动，继续穿过 D3 和 END，抵达 `d = 4.08`。

一次“回退”指 `D2 → D1 → D2` 的完整复位循环，不要求把钥匙整根拔出。旋转自由段位于 `d = 1.5`，不在钥匙齿仍穿过锁片时直接换槽。

被动驱动使用有余隙的准静态关系：正转时 `α_i' = max(α_i, θ − s_i − m)`，反转时 `α_i' = min(α_i, θ − s_i + m)`。生成器在每次首次接触槽壁处切分路径。因此盘角改变的每个区间都满足 `θ − α_i − s_i = ±m` 且 `dθ = dα_i`，脱开后的盘角保持不变。这补上了“钥匙和锁片一起转，但齿实际还在槽中心”的不成立假设。

## 3. 连续路径检查与回退次数下界

对第 `k` 个齿与第 `i` 片板，轴向重叠区间满足 `|d − (i+k+1)| ≤ (10+5)/(2×150) = 0.05`。检查器准确求出每条路径段进入、离开这些区间的位置，再检验整个区间的相对角度是否始终落在同一个槽的 ±4° 内。每段角度是仿射函数，检验两端即可覆盖内部；同时检查三盘限位与上述被动槽壁驱动关系。

| 指标 | easy | medium | hard |
| --- | ---: | ---: | ---: |
| 检查的齿／板重叠区间 | 38 | 52 | 66 |
| 锁片受槽壁驱动的区间 | 6 | 10 | 14 |
| 最小限位余量 | 1° | 1° | 1° |
| 最小槽壁角余量 | 0°，有意接触驱动 | 0°，有意接触驱动 | 0°，有意接触驱动 |
| 保守轴／孔径向间隙 | 0.97146 mm | 0.97146 mm | 0.97146 mm |
| 末态前齿后缘超出 END 外表面 | 4.5 mm | 4.5 mm | 4.5 mm |

径向界使用碰撞网格至多 10° 扇区对应的内接弦下界 `7.5 cos(5°) − 6.5` mm，未把名义圆孔的 1 mm 当作网格精确间隙。它只覆盖孔槽部分，外部框架、桌面、抓手碰撞不在该解析证书内。

**为何分别至少回退 1／2／3 次：** 两片同时啮合第 `j` 个分支时，`α2 − α1 ∈ [s_j−s_0−2m, s_j−s_0+2m]`。这些相对角度带互不相交；两片脱开且都保持不动时，单独转钥匙无法切换分支。结合 D1 限位，D2 在各分支上的允许区间为：

- easy：`[−10,23] → [7,45]`。
- medium：`[−10,23] → [7,53] → [37,75]`。
- hard：`[−10,20] → [4,44] → [28,68] → [52,87]`。

区间图允许所有角余隙、所有自由空隙转向，并保守地允许区间相交的任意分支切换；三图仍只连接相邻分支。初态只能进入首分支，进入初始 D3 需要末分支。因此最短分别为 1、2、3 次解耦复位，构造路径达到此下界。

该最短性仅适用于**同轴、准静态、仅钥匙齿侧壁驱动**模型，假定脱开的盘能保持角度。它不排除利用端面摩擦、偏轴楔入、惯性冲击或其他工具接触的路径，也不提供动力学稳定性结论。
