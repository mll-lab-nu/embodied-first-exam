# 当前 Demo

视频统一采用 `demos/<task_name>/varaition_<id>/<camera>/<file>.mp4`，沿用用户指定的 `varaition_` 拼写。基础实例也使用具名变体目录；每个变体分别保留，每个相机叶子目录一份独立 MP4，正式完整版优先。源码入口在 `environment_bootstrap/`，开发中尝试留在对应 `runs/`。

例如 Buzz Wire 为 `varaition_f1_vertical_wave/`、`varaition_f2_over_under_eight/`、`varaition_f3_plane_switch/`，各自下分 `agentview/`、`front_oblique/`、`wrist/`。Buzz Wire 只保留三个已验收代表的最新完整三视角，共 9 份 MP4；旧预览和诊断位于开发记录。迁移核对见[目录清单](../runs/demo_metadata/directory_layout.json)。

当前正式视频的逐帧计数、完整解码、SHA-256 与同组同步检查见各自归档。Buzz Wire 按 F1/F2/F3 分开保存三路完整版；视频重渲染与物理执行资格分别记录。

Buzz Wire 当前为 **home_lab_v4**：公共实验室背景，从默认 home 连续执行拾取、全关卡、支撑放回及静置；F1 82.07 s、F2 136.63 s、F3 131.47 s，均通过 4/2 ms 复验。视频列于下方公共录制目录，完整 IK 与证据见[任务说明](../docs/develop/tasks/buzz_wire_3d_zh.md)，当前九路核对见[交付检查](../runs/demo_metadata/buzz_wire_3d/home_lab_v4_validation.json)。
