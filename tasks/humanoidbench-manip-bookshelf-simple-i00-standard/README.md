# humanoidbench-manip-bookshelf-simple-i00-standard

Standard mode (robot as a service, `eai-standard/2.1`) of `humanoidbench-manip-bookshelf-simple-i00`: the same
frozen instance and the same success rule. HumanoidBench runs in the `sim` sidecar
(`environment/docker-compose.yaml`, GPU on the sidecar for rendering), which holds the reward, judges the
episode, records it, replays it in a fresh simulator and renders the replay video; the verifier grades the
sidecar's record in a container of its own (`tests/Dockerfile`, no network).

| | |
|---|---|
| mode / sensors | standard: head-camera RGB + joint angles and velocities (HumanoidBench's own `image` and `proprio` sensors), a pelvis IMU and a camera fixed in the room; no root pose, no object positions, no reward; one episode, no reset |
| action space | HumanoidBench's own: 61 normalised position targets, 50 Hz, sent in chunks |
| knobs (compose env) | `RCB_RESET_BUDGET` (0), `RCB_OBS_PROPRIO` (1), `RCB_OBS_IMU` (1), `RCB_OBS_ROOM_CAMERA` (1), `RCB_OBS_DEPTH` (0): the defaults are the standard configuration; a run that changes one (`RCB_RESET_BUDGET=50 harbor run ...`) is reported separately, and `episode.jsonl` records the `/spec` it ran under |
| agent API | `environment/rcb_client.py` (its docstring is the reference); `instruction.md` lists the endpoints |

Note: the head cameras see the inside of one shelf. `room_camera` looks at the shelves from behind the robot's
right shoulder (`RCB_ROOM_CAMERA_POSE` in the compose file) and sees the bookshelf, the objects' places on it
and the robot.

## Difficulty
See `humanoidbench-manip-bookshelf-simple-i00`'s README; here the agent also has no state, no reward, no
resets and no simulator of its own.

## Reference solution
None. Requiring one would cap the benchmark at what we can already solve, which systematically removes the
interesting tasks. What replaces it (docs/PROTOCOL.md §2.7): the floor above (doing nothing cannot pass), the
evidence that the task has a solution (`oracle_evidence` in task.toml), and a human reviewer.

## Verification
`success` = live success (the episode's return reached the pass mark) ∧ replay success ∧ deterministic (the
fresh replay ends in the live run's state), computed in the sidecar; `tests/grade.py` reads `/data/final.json`
and copies the evidence to `/logs/verifier/` (`replay.mp4`). No oracle; human review in PR #9. `nop` scores 0.

Generated by `scripts/humanoidbench/gen_tasks.py` from `subset.toml`, `templates/standard/` and
`shared/standard/`.
