# Embodied First Exam

**Can a coding agent program a robot?** Robot-manipulation tasks for coding agents (Claude Code, Codex, …) in the
[Harbor](https://github.com/harbor-framework/harbor) task format.

**Website, leaderboard and videos: [embodied-first-exam.ai](https://embodied-first-exam.ai)**

## Quick start

```bash
git clone --recurse-submodules git@github.com:mll-lab-nu/embodied-first-exam.git && cd embodied-first-exam
uv tool install --force -e . --with-executables-from harbor     # harbor 0.23.0 with the flags below
cp .env.example .env

harbor run -a codex -m openai/gpt-6-luna              # core: one mode per task (default, --core)
harbor run --core-all -a codex -m openai/gpt-6-luna   # core-all: every dir of docs/core_set.toml, every mode
harbor run --all -a codex -m openai/gpt-6-luna        # every task
harbor run -p tasks/roboarc -a codex -m openai/gpt-6-luna   # every task of one benchmark (here RoboARC)
harbor run --standard -a codex -m openai/gpt-6-luna   # core-standard (also --privileged / --standard-realtime)
harbor run -p tasks/<benchmark>/<task> -a oracle      # one task
```
