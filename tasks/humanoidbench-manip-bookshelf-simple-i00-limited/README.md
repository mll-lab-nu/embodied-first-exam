# humanoidbench-manip-bookshelf-simple-i00-limited

Limited-mode twin of `humanoidbench-manip-bookshelf-simple-i00` (same frozen instance, same success rule): the
agent gets only the `rcb-limited/1.1` client; HumanoidBench runs in the `sim` sidecar
(`environment/docker-compose.yaml`, GPU on the sidecar for rendering), which holds the reward, judges the
episode, records it as a trajectory, replays it from the frozen instance for success + determinism, and
renders the replay video. The verifier runs in a separate sandbox (`tests/Dockerfile`) over the sidecar's
artifacts. Compare against the unlimited task to measure the cost of losing resets, privileged state and the
ability to search.

| | |
|---|---|
| tier / mode | perception / limited: head-camera RGB + joint angles/velocities (HumanoidBench's own `image` + `proprio` sensors); no root pose, no object positions, no reward; no reset by default |
| action space | HumanoidBench's own: 61 normalised position targets, 50 Hz; one per request or a batch of K |
| knobs (compose env) | `RCB_RESET_BUDGET` (0), `RCB_OBS_PROPRIO` (1; 0 = images only), `RCB_OBS_IMU` (0), `RCB_OBS_ROOM_CAMERA` (0), `RCB_OBS_DEPTH` (0). Per run from the shell (`RCB_RESET_BUDGET=3 RCB_OBS_IMU=1 harbor run ...`) or a profile (`harbor run -c scripts/humanoidbench/configs/limited-depth.yaml ...`); the start line of `episode.jsonl` records the resulting `/spec` |
| agent API | `environment/rcb_client.py`: its docstring is the full reference; `instruction.md` points to it and keeps only task facts |
| reference solution | none, on purpose; the nop agent scores 0 |
| verification | `success` = live success ∧ replay success ∧ deterministic, computed inside the sidecar; `/logs/verifier/replay.mp4` |
| code | copied from `robotwin_2_0_stack_blocks_two-limited` (dev/kangrui) and split: `sim/rcb_service.py` is simulator-agnostic, `sim/server.py` is the HumanoidBench adapter. See `docs/LIMITED_MODE_1_1.md` |

Note: the head cameras see the inside of one shelf. `room_camera` (off by default) looks at the shelves from
behind the robot's right shoulder (`RCB_ROOM_CAMERA_POSE` in the compose file) and sees the bookshelf, the
objects' places on it and the robot.

Generated by `scripts/humanoidbench/gen_tasks.py` from `subset.toml`, `templates/limited/` and
`shared/limited/`; agent runs are recorded in `results/humanoidbench/`.
