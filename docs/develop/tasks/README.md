# tasks — 任务设计与落地计划

docx 里定义的 20 个任务，各自要在哪个类别子目录下实现、需要什么环境、按什么顺序做。

与 `../physics/` 的分工：本目录记设计契约与落地计划（随类别与判定契约变化）；`../physics/` 记
实现过程中的物理调参与 debug（随物理引擎变化）。
