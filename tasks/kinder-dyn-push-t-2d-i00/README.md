KinDER `kinder/DynPushT2D-t1-v0` (Dynamic2D, Pymunk), seed 0, full mode: the agent has the simulator and its state and
hands in one trajectory, replayed open-loop in a fresh process.

Task: push the grey T-shaped block (`tblock`) with the blue dot robot (`robot`) onto the light-green T drawn on the floor (`goal_tblock`), which nothing collides with.
