## Task
HumanoidBench spoon: produce one replayable trajectory that stirs a cup with a spoon held by the Unitree H1, frozen scene instance 00.

## Difficulty
The pass mark is a **threshold on the whole episode's return** (`>= 650` over 1000 steps), not a
predicate on the final state.

- **Periodic end-effector tracking — the only instance of it in the subset.** `walk` needs a limit
  cycle in the legs against ground contact; this needs one in the hands against a clock, with the phase
  fixed by the environment rather than chosen by the agent. 40 steps per revolution at 50 Hz is 1.25
  revolutions a second.
- **🚩 The published best is *below* the give-away floor.** FastTD3 reaches 369/650; holding the starting
  pose scores 375.45 — standing and a hand near the handle pay for it, although the spoon starts on the
  table beside the cup. That is the sharpest illustration in the subset of why completion
  rate alone is the wrong selection criterion.
- **⚠️ The highest give-away in the scored subset: 57.8% of the bar.** It was kept on the argument that
  the remaining 42% is periodic tracking, but by the formula it is not: the circling term's tolerance
  (0.15 m) is wider than the circle's radius (0.06 m), so a spoon held still at the centre of the cup
  scores about 0.84 a step against the 0.65 the bar needs. What remains is getting the spoon into the
  cup, which makes this the first task to reconsider. The `verify` threshold carries an explicit
  exemption for it, so this is recorded in code and not just in prose.
- **61 actuators**, and the grip has to survive a sustained oscillation.

**Measured floors** (this instance, `scripts/humanoidbench/gen_tasks.py verify`): an all-zero
trajectory scores **7.48 / 650** (the episode terminates at step 63 of 1000). Holding the starting
pose instead — the floor a competent agent gets before writing a controller — scores **57.8%** of
the bar; that is the number this task was selected on (the give-away limit of `gen_tasks.py
verify`). **External evidence**: published RL results reach **57%** of the bar (paper 322, FastTD3
369, bar 650) — training runs of millions of environment steps, not a one-hour coding session, so
treat it as proof that the task *has* a solution rather than as a target.

**The agent does not see the reward function.** It is deleted from the image and restored only
inside the verifier (`images/humanoidbench/scrub_oracles.py`, `tests/rcb_rewards.py`), so the
numbers above are comparable with the paper while the agent works from the task statement and the
physical state alone.

## Reference solution
None. Requiring one would cap the benchmark at what we can already solve, which systematically
removes the interesting tasks. What replaces it (docs/PROTOCOL.md §2.7): the floor above (doing
nothing cannot pass), the evidence that the task has a solution (`oracle_evidence` in task.toml),
and a human reviewer.

## Verification
In its own container, built from `tests/Dockerfile` (no network): the agent's container is gone by
then, and only `/app/output/` crosses over. Open-loop replay of `/app/output/trajectory.npz` from
`tests/instance.npz` in a fresh process, twice; pass iff every replay's episode return reaches
`success_bar` **and** the final-state hashes agree (bit-exact determinism). `tests/grade.py` also
writes `/logs/verifier/replay.mp4` and, because Harbor promotes every `reward.json` key to a
leaderboard metric, keeps the per-task numbers (`episode_return`, `success_bar`) in
`/logs/verifier/diagnostics.json`. No oracle; human review in PR #9. `nop` scores 0.

### GPU
Optional, and passing never depends on it: MuJoCo physics is CPU-only, so a GPU only speeds up the
agent's own offscreen rendering (osmesa ~130 ms/frame, egl ~0.4 ms). Hand one to the agent's
container with `--extra-docker-compose environment/gpu.docker-compose.yaml`; `rcb_hb.py` then picks
EGL by itself unless `MUJOCO_GL` says otherwise. The overlay is not named `docker-compose.yaml`
because Harbor would load that on every machine, and a device reservation the host cannot satisfy
stops the container from starting.

### Provenance
Generated by `scripts/humanoidbench/gen_tasks.py` from `scripts/humanoidbench/subset.toml`.
Everything in this directory except the instance (`environment/instance.npz` and its byte copy
`tests/instance.npz`) is reproducible with `gen_tasks.py render spoon`; the instance with
`gen_tasks.py instance spoon` (seed 0, sha `11a38054aebb`).
