# TopoGym main environment, excluding PyTorch CUDA wheels.

# Install torch/torchvision from the selected PyTorch CUDA index first, then:
#   uv pip install --python .venv-gs121/bin/python \
#       -r requirements/uv-topogym-gs121.txt
#
# These direct pins mirror the gs110 environment, except Genesis is upgraded
# from 1.1.0 to 1.2.1 (latest stable, released 2026-07-03). Genesis installs
# its matching Quadrants version (quadrants==1.0.2) transitively; do not pin it
# here. Genesis 1.2.1 requires Python >=3.10,<3.14 and numpy>=1.26.4, both of
# which the pins below satisfy.
#
# Relevant breaking changes vs 1.1.0 to watch for after install:
#   - 1.2.0: kinematic trees are now parsed depth-first (was breadth-first);
#     any code relying on robot link/joint ordering may need review.
#   - 1.2.0: islands partitioning is enabled by default.
#   - 1.2.1: center-of-mass alignment fixed for composite links (rigid dynamics
#     behavior may shift slightly).
#   PBD/FEM/MPM deformable solvers were not changed, so cable_routing / untangle
#   / peeling flows should be unaffected.
