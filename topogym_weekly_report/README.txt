TopoGym - weekly report deck (2026-08-26)

HOW TO OPEN
-----------
Do NOT double-click presentation.html (browsers block fetch()/video on file://).
Serve the folder and open it over http:

    cd topogym_weekly_report
    python -m http.server 8000

then open   http://localhost:8000/presentation.html

NAVIGATION
----------
  left / right arrows   previous / next slide
  up / down arrows      scroll within a slide
  type a number + Enter jump to that slide
  G                     slide index
  F                     fullscreen

CONTENTS
--------
  presentation.html   the deck (35 slides: Part 1 plan & progress / Part 2 per-task demos / Part 3 variation plan)
  assets/topogym/     copies of runs/videos/<task>/*.mp4 (51 clips, all square)
  assets/, mm_gallery/, index.html   leftovers from the Real2Sim template, not referenced by the deck

EDITING
-------
The original template was generated by _gen/build_index.py, which is not in this
package. presentation.html is now edited directly; the builder script used for the
TopoGym content lives outside the repo (scratchpad build_topogym_deck.py).
