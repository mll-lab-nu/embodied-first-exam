# kinder-table-3d-i00

KinDER `kinder/Table3D-o3-v0` (Kinematic3D, PyBullet), seed 0, full mode: the agent has the simulator and its state and
hands in one trajectory, replayed open-loop in a fresh process. Its limited-mode twin is `kinder-table-3d-i00-limited`.

Task: pick up one of the three small purple cubes (`cube0`, `cube1`, `cube2`) from the wooden table (`table`). The task succeeds the moment the robot is holding a cube whose centre is more than 0.1 m above the table top, that is, higher than 0.5 m above the floor.

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
