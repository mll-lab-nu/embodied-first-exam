# kinder-shelf-i00-limited

Limited mode (robot as a service, `docs/LIMITED_MODE_1_1.md`) of `kinder-shelf-i00`: the same KinDER instance
(`kinder/Shelf3D-o2-v0`, seed 0) runs in the `sim` sidecar; the agent gets a client and the robot's own sensors -- two
cameras, joint encoders, the base's odometry -- and never the scene's state or the goal check.

Task: pick up the dark-red cube and the dark-green cube from the floor and put both in the top compartment of the brown cupboard, which has three compartments one above another. The task succeeds the moment both cubes rest on that compartment's floor.

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
