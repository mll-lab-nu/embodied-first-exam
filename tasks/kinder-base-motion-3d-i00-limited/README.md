# kinder-base-motion-3d-i00-limited

Limited mode (robot as a service, `docs/LIMITED_MODE_1_1.md`) of `kinder-base-motion-3d-i00`: the same KinDER instance
(`kinder/BaseMotion3D-v0`, seed 0) runs in the `sim` sidecar; the agent gets a client and the robot's own sensors -- two
cameras, joint encoders, the base's odometry -- and never the scene's state or the goal check.

Task: drive the robot's base to the small red ball that hovers 0.2 m above the floor. The task succeeds the moment the centre of the base is less than 5 cm from the ball's centre, measured horizontally; the base's heading is not checked.

Generated by `scripts/kinder/gen_tasks.py` from `scripts/kinder/subset.toml`; see `docs/benchmarks/kinder.md`.
