# metaworldplus-box-close-i00

MetaWorld+ privileged task: Meta-World's `box-close-v3` (Sawyer, reward v2) on one frozen instance. Generated by
`scripts/metaworldplus/generate.py`; benchmark notes in `docs/benchmarks/metaworldplus.md`.

| | |
|---|---|
| source | [Meta-World](https://github.com/Farama-Foundation/Metaworld) @ 59fc34d (MIT) on MuJoCo 3.3.0; image `eai-metaworld:0.1.0` |
| instance | Meta-World's reset randomization with seed 0; MuJoCo state, model arrays, env caches and RNG frozen in `instance.npz` (SHA-256 `0982332c188e…`, checked on load) |
| deliverable | `(T, 4)` native actions `[dx, dy, dz, grip]`, 1 ≤ T ≤ 500 (Meta-World's `max_path_length`) |
| success | Meta-World's own check (`evaluate_state`) on the state after the last action |
| actions | no `joint_position`: Meta-World's Sawyer has no arm actuators (the hand is a mocap body, the arm follows it) |

## Difficulty
Full privileged state, unlimited resets and self-replay. This mode is the control for the standard twin: under the
earlier two-mode protocol (success at any step), Codex with GPT-6 Luna (high) solved every privileged MetaWorld+
trial. The difficulty of the benchmark is in the standard twin.

## Reference solution
Meta-World's scripted policy for `box-close-v3` (`metaworld/policies/`, removed from the image), run on this instance up to
its first success: 103 actions in `solution/oracle.npz` (recorded by `scripts/metaworldplus/freeze.sh`).

## Verification
`tests/grade.py` in a separate sandbox without network: two replays in fresh processes from the verifier's own copy of
the instance; `success = deterministic ∧ success on the final state`. Oracle: two fresh-process replays end in the
live episode's state (hash `4ccfeda8a046…`) and succeed. `nop`: no trajectory, reward 0; the instance is
not solved at the start.
