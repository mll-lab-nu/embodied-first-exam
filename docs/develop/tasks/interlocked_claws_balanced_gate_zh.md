# Claw C0：紧凑、全等的正交双窗

2026-09-19：按“接近基础 demo 尺寸、左右完全均衡”的要求重建 C0。模型 ID 为 `orthogonal_gate_balanced_v2`，仍属于 C 正交换轴 family。两个窗口全等，完整双臂辅助抓持执行与半步长复验均通过。

## 结构尺寸

| 项目 | 旧 C0 大框版 | 当前 C0 等尺寸版 |
| --- | --- | --- |
| 橙色框架整体包围盒 | 约 739 × 460.5 × 381 mm | 252 × 252 × 190 mm |
| 两窗比例 | 第二窗明显放大，附加外部握柄 | 两窗外框均为 250 × 190 mm |
| 净开口 | 两侧不相等 | 两侧均为 220 × 160 mm |
| 厚度 / 边框宽 | 按旧模型保留 | 两侧均为 14 / 15 mm |

基础 A0 原件的最大尺寸约 264 mm；新版框架最大尺寸 252 mm，与其处于相近尺度。蓝色钥件尺寸为 250 × 28 × 182 mm。橙色框架局部坐标下，变换 `(x,y,z) → (y−0.12,x+0.12,z)` 精确交换两窗及连接角；测试直接核对全部碰撞盒体，避免仅靠视角判断平衡。

橙色框架由八个盒体并集构成，蓝色件由两叉、连接桥及横向夹持杆并集构成。每件均为单个连通水密实体；可见表面与碰撞盒体的实体并集一致，质量、质心和惯量由最终并集计算。没有用隐藏扩大开口的碰撞模型替代可见结构。

## 完整动作与视频

| 时间 | 动作 |
| --- | --- |
| 0–1 s | 已预抓取，短暂停留 |
| 1–5 s | 第一轴翻转 90° |
| 5–11 s | 穿过第一窗并侧移至转向空间 |
| 11–19 s | 第二轴转动 90° |
| 19–27 s | 对准第二窗并退出 |
| 27–34 s | 保持两件相对间隙，共同转向，蓝色件落桌 |
| 34–38 s | 解除蓝色件抓持，左爪张开并沿窗口退回 |
| 38–54 s | 右臂搬运框架、降低到桌面 |
| 54–62 s | 解除框架抓持，右臂退回，两件自由静置 |

先松开蓝色件并撤手，解决了小框在搬运时跨过仍穿在窗内的前臂的问题；因此无需再次放大某一侧窗口。C0 的两次正交换轴机制保持不变。

五路均取自同次连续物理执行的完整实测状态，1,241 帧、20 fps，成片 62.05 秒；视频未拼接不同执行。

## 验证结果和范围

| 检查 | 结果 |
| --- | --- |
| 全等性、连通水密、正定惯量、抓点在实体内 | 通过 |
| 理想相对路径连续几何检查 | 通过，采样最小间隙 11 mm |
| 双臂 IK 与机器人碰撞采样 | 通过，0 个碰撞帧 |
| 独立重力落桌、受力正向路径 | 0.25 / 0.125 ms 两档通过 |
| 保持姿态、省略第一 / 第二次转向的错误动作 | 两档均被实体阻挡 |
| 连续机器人执行、依次松手与无机器人支撑的桌面静置 | 两档均通过 |

| 原关节驱动力上限（含重力补偿）、模拟器警告 | 上限通过，无警告 |
| 相关回归测试 | 20 项通过 |

采用 MuJoCo 3.13.0、重力 −9.81 m/s²，自由刚体与接触持续启用。执行从预抓取起点开始，使用显式理想焊接辅助；34 / 54 秒分别解除两侧辅助，最后一秒无机器人接触支撑。初始夹持接触约 0.806 mm 属于该辅助抓持设置，不能解释为纯摩擦抓持已经可靠。初始化后不写入物体位姿，视频仅重渲染记录状态，不构成第二次动力学执行。

短程物理预测得到蓝色件松手后的静置位置，仅用于后续框架搬运的名义碰撞检查；最终两档完整运行均从初态重新连续积分，没有在中途重置到预测位置。归档保留该短程预测及其来源哈希；其报告因框架仍被抓住而不满足完整任务终态，这是明确的局部诊断，不作为完整成功报告。

连续几何证书只覆盖理想件间路径；实际机器人路径另经 IK 采样和物理接触监测。两条错误动作对照使用姿态保持控制，不证明全局唯一解。本轮验证固定实例的辅助抓持解法，不覆盖纯摩擦抓取、自主求解、实机或随机参数域。

近景使用 v2 取景，完整保留落桌后的框架边缘；其余四路仍为 v1。五路来自完全相同的物理状态记录，近景换镜头不涉及重新执行动力学。旧 v1 近景作为历史版本保留。
